# DozzyFlow-Task-Manager-App
Technologies: React, Redux Toolkit, TypeScript, Jest, Vercel

Developed a Task Management web application using React and Redux Toolkit to showcase expertise in front-end development and state management.

Implemented CRUD operations (Create, Read, Update, Delete) for tasks and integrated features like marking tasks as complete and filtering by status.

Ensured data persistence by leveraging localStorage to save tasks, providing a seamless user experience.

Wrote comprehensive unit tests for Redux reducers and React components using Jest and React Testing Library, achieving high test coverage and ensuring code reliability.

Utilized TypeScript to build a robust, type-safe codebase and deployed the application on Vercel for public access.
